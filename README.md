## Deployment & Infrastructure

<div align="center">

| Layer | Details |
|:---|:---|
| **Hosting** | GCP for Electro, Railway for Speak & Shine, Vercel for static and frontend deployments |
| **Object Storage** | Cloudflare R2 with direct browser uploads and SSRF-protected fetches |
| **Media CDN** | Cloudinary for image optimization and transformation |
| **Caching** | Redis for sessions, rate limiting, and security scan cache |
| **Authentication** | 15-minute JWT access tokens and 7-day refresh tokens with rotation and reuse detection |
| **Security Headers** | Helmet.js with CSP, HSTS, `object-src: none`, and `frame-src: none` |
| **Configuration** | Environment-based config with startup validation for required secrets |
| **Proxy** | Trust proxy enabled for correct client IP handling behind Railway |

</div>

---

## Development Philosophy

- **Security first:** authentication, validation, and rate limiting belong in the foundation.
- **Production ready:** configuration, logging, and error handling start early.
- **Real-time where useful:** Socket.io and Redis power live, responsive workflows.
- **Performance minded:** cache aggressively, validate early, and fail clearly.
- **Product focused:** build projects that are useful, deployed, and maintainable.
